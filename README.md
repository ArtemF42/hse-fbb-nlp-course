# Natural Language Processing @ HSE FBB

Курс по обработке естественного языка для студентов 4 курса бакалавриата Факультета биологии и биотехнологии НИУ ВШЭ.

## Installation

```bash
git clone https://github.com/ArtemF42/hse-fbb-nlp-course.git  && cd hse-fbb-nlp-course
uv venv && source .venv/bin/activate && uv pip install -r requirements.txt
```
